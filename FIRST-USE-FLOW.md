# First-use flow

Status: proposed interaction structure for low-fidelity design, not a validated flow or approved visual direction.

## 1. Your museum — empty state

Purpose: explain the value and give one clear starting point.

- Heading: “A place for the things that mean something.”
- Supporting text: “Bring three objects together around a chapter of your life. Add a note if you like, and return whenever you want.”
- Primary action: “Create an exhibition”
- Small examples: “My first apartment,” “Things Dad says,” “A summer that felt different.”

Examples should inspire rather than require a category choice.

## 2. Name a chapter

Purpose: give the collection a focus before choosing objects.

- Heading: “What chapter are you keeping?”
- One exhibition-name field.
- Placeholder: “My first apartment”
- Primary action: “Add objects”
- Allow continuing with “Untitled exhibition” if someone has not chosen a name.

## 3. Add objects

Purpose: make a small collection from material the person already has.

- Heading: “Choose three things that belong here.”
- Helper: “Photos, screenshots, audio, or a photo of something you kept.”
- Three initial object slots, with one clear add action.
- Show upload progress, retry on failure, and a way to remove or replace each item.
- Allow proceeding with fewer than three objects; never require placeholder content.
- A visible save-draft action preserves incomplete work.

For the first prototype, use existing-file upload. In-app recording and camera capture remain later possibilities.

## 4. Add optional context

Purpose: preserve meaning without making writing a chore.

- Show the selected object prominently.
- Optional title and note fields.
- Note prompt: “What would you like to remember about this?”
- Clear “Skip” and “Next object” actions.
- Audio objects have user-controlled playback.
- Preserve entered text when navigating backward.

Avoid calling this step “Add a story,” which can suggest social-media content or a longer writing task.

## 5. Preview your exhibition

Purpose: deliver the sense of a small exhibition without requiring layout expertise.

- Show the exhibition title and an automatic arrangement of its objects.
- Select an object to see its note or play its recording.
- Offer simple reorder and edit actions; provide button controls alongside any dragging.
- Display “Private — only you can view this.”
- Primary action: “Save exhibition”
- Confirm successful saving; show a recoverable error if saving fails.

This is the key visual moment to explore after the structure is clear. Typography, materials, color, and spatial treatment remain open.

## 6. Your museum — with an exhibition

Purpose: make the return path obvious.

- Show the saved exhibition as a recognizable card with its title and object preview.
- Clicking the card opens the exhibition in viewing mode.
- An “Edit exhibition” action returns to editing.
- Show incomplete work with an explicit “Draft” label and “Continue” action.
- Keep “Create an exhibition” available.

## Prototype evaluation tasks

Use participant-selected, non-sensitive material or clearly labeled sample assets. Avoid suggesting that anyone must disclose personal memories.

1. “Make a small exhibition about a chapter you choose.” Observe whether the starting point and object formats are understood.
2. “Add some context to one item and leave another without a note.” Observe whether optionality is clear.
3. “Save it, leave the exhibition, and find it again.” Observe whether saving and navigation are understandable.
4. “Change an item in your exhibition.” Observe whether viewing and editing are distinguishable.
5. “Who do you think can see this exhibition?” Check whether privacy is understood without prompting the answer.

Capture completion, points of confusion, unexpected behavior, and participant comments. A successful immediate return task demonstrates findability, not evidence that people will return days later.
